1 · The TUI, redesigned: click it, then use vim keys

Each query gets a tab. Purple tabs are queries an agent ran, with its stated reason shown above the SQL. The sidebar shows row counts, so empty tables are visible before you open one.

2 · How agents and you share one query log

Agents call the CLI. Every run is appended to a log file, and a TUI started with --follow opens a tab for each new entry. Nodes marked new don't exist yet; the others are today's code.

3 · Agents use the CLI first; MCP can wait

Agents already run shell commands, so a good CLI works with every agent today. An MCP server could later wrap these same commands without changing them.

# discover
dbbie connections --json
dbbie tables  --conn local --match 'balance*' --json      # + estimated row counts
dbbie describe --conn local --table balanceapi_account --json

# run: every query is logged with who ran it and why
dbbie query --conn local --why "find businesses with no balance account" \
  --sql "select ..." --limit 50 --json                    # → {"id":"q_0042", rows, truncated, ...}

# read back without re-running
dbbie show q_0042 --offset 50 --limit 50 --json             # page through a saved preview
dbbie log --conn local --json                               # what has run this session

# watch it live
dbbie open --conn local --follow                            # a tab opens per new agent query

Contract: --json is the default when stdout isn't a terminal · errors come back as {"error":{"code","message"}} with a non-zero exit code · dbbie tools --json lists all of this for agents to discover.

5 · What changes from today

  • Search knows its pane. Today / only filters result rows. Now it filters table names in the sidebar and rows in the results, and t finds a table from anywhere.
  • Table names fit. A flat list replaces the tree, so names are no longer cut off, and each shows an estimated row count (empty tables are dimmed).
  • Columns size to their data. Timestamps are shortened to 2026-10-05 16:48, NULL is dimmed, numbers are right-aligned, and every header shows its type.
  • Calmer highlighting. The current row is a subtle band and the current cell a solid block, instead of everything in bright yellow. Panes use single borders, with the focused one in blue.
  • The footer reads the current cell: column, type, its full value, and the row position. An empty result says "0 rows" instead of showing a blank grid.
  • Queries run in the background, so a slow query no longer freezes the UI; Ctrl-c cancels it.
